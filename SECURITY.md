# Security Policy

## Reporting a vulnerability

Do not open a public issue for an undisclosed vulnerability. Use GitHub's private vulnerability reporting feature when it is enabled for this repository.

Include the affected file or workflow, impact, minimal reproduction, and a safe remediation idea. Do not include real credentials, customer data, private endpoints, or third-party confidential material.

## Scope

The architecture probe is a lightweight hygiene gate. It intentionally suppresses matched values and locations, but it is not a complete secret scanner, malware scanner, or compliance tool. Review derivative artifacts manually before publication.
